## 🚀 Running Locally

```bash
# Start server
npm run preview -- --port 3000 --host
```

Open `http://localhost:3000` in your web browser. Use the **[👷 Håndværker Portal]** / **[🏡 Boligejer Portal]** switcher in the top navigation bar to toggle between both roles instantly.
